Swarmy design concepts

Five different ways the same app could work, all in the Forest palette so you can compare layout, navigation and type rather than colour. Each uses the same demo torrents.

Control room

Dense and keyboard-first. Filters, a compact table and an inspector with a piece map, all on one screen. For people who live in the app.

Desktop, dark

Pipeline

A board. Torrents move left to right through stages, and anything broken lands in "Needs you" with a button to fix it.

Desktop, light

Library

A media shelf. What Sonarr and Radarr fetch shows up as covers on shelves, with the current download featured at the top.

Desktop, dark

Field station

An instrument panel. Analog gauges for speed, disk and CPU, each download as a trail with checkpoints, and a logbook.

Desktop, light

Pocket

Phone first. Progress rings, stacked widgets and a bottom tab bar, built for one thumb.

Phone, dark
